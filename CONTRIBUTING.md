# Contributing

Small fixes, bug reports and compatibility reports are welcome.

- For bugs, include your macOS version, Smallibre version, steps to reproduce, and expected versus actual behavior. For reader issues, include the model and connection type. Remove private paths and book details from logs; do not upload copyrighted books.
- Open an issue before a large feature so we can agree on scope.
- Keep pull requests focused. Explain the change and how you checked it; add regression coverage for behavior changes. Run `swift test` and `bash scripts/build-app.sh` for code changes.
- See [AGENTS.md](AGENTS.md) for architecture, local setup and safe device testing. Contributions are under the project's [GPL-3.0-only license](LICENSE).

For a security issue, follow [SECURITY.md](SECURITY.md).
